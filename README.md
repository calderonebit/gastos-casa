# Gastos de Casa

App Android para registrar las compras diarias de la casa (Carlos y Mirna, mitad y mitad).

- Registro con fecha y hora automáticas (no se cambian)
- Cantidad con medida: unidad, kg, g, bolsa, bolsita, paquete, sobre, litro, botella, docena, atado, caja, lata
- Categorías: Alimentación, Limpieza, Otros
- Resumen de la semana (lunes a domingo) por día, con el total y la mitad para cada uno
- Botón para enviar el resumen por WhatsApp
- Copia de seguridad y restauración

El APK se construye solo con GitHub Actions al subir cambios a `main`
y queda para descargar en la sección **Releases** del repositorio.
